## 🤖 ProofTrack

### Verify Claims With Evidence

ProofTrack is an **AI-assisted claim verification platform** that analyzes claims against information collected from web sources.

It combines **rule-based analysis with Google Gemini AI** to determine whether evidence **supports, contradicts, or is insufficient** for a claim.

### ✨ Highlights

- 📝 Claim creation & management
- 🌐 Web source collection
- 📄 Evidence extraction
- 🤖 Google Gemini AI analysis
- ⚙️ Rule-based verification
- 📊 Confidence scoring
- 🔍 Claim-evidence relationship analysis
- 🔐 URL validation
- 🛡️ SSRF protection
- 🗄️ Persistent database storage

### 🛠️ Tech Stack

`React` `Node.js` `Express.js` `Google Gemini` `Axios` `Cheerio` `MySQL` `REST APIs`

🔗 [View Project](https://github.com/abhi1289-gif/ProofTracker)

🌐 [Live Demo](https://prooftrack-zeta.vercel.app/)
